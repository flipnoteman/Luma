# Views and writes

This chapter is not written yet. Views (`slice`, `pad`, `flip`, `transpose`, `shift`, `take`, `concat`, `stack`, `broadcast_to`) read the array they are made from inside the kernel that uses them, so they cost no copy; writes go through mutable views (`slice_mut`, `flip_mut`, `transpose_mut`) with `assign`, compound assignment and `put`. See [`Array::slice`](https://docs.rs/luma/latest/luma/struct.Array.html#method.slice), [`PadMode`](https://docs.rs/luma/latest/luma/enum.PadMode.html), [`ViewMut`](https://docs.rs/luma/latest/luma/struct.ViewMut.html), [`concat`](https://docs.rs/luma/latest/luma/fn.concat.html) and [`stack`](https://docs.rs/luma/latest/luma/fn.stack.html). Runnable material: [`tests/views.rs`](https://github.com/flipnoteman/Luma/blob/main/tests/views.rs) and [`tests/assign.rs`](https://github.com/flipnoteman/Luma/blob/main/tests/assign.rs).
